# Panduan unggah GitHub

1. Buat repositori bernama `Grokking-Deep-Learning`.
2. Unggah isi folder ini sehingga `README.md` berada di root repositori.
3. Sertakan `notebooks/`, `data/`, `docs/`, `scripts/`, requirements, dan `NOTICE.md`.
4. Jangan unggah PDF buku, virtual environment, cache, atau folder sumber kerja.
5. Buka seluruh notebook di GitHub dan pastikan Markdown, kode, serta output dapat dirender.
6. Periksa kembali nama, NIM, kelas, atribusi, dan aturan pengumpulan sebelum mengirim tautan.
