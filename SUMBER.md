# Sumber kode dan data

- Referensi utama: Andrew W. Trask, *Grokking Deep Learning*, Manning, 2019, ISBN 9781617293702.
- Kode pendamping resmi: https://github.com/iamtrask/Grokking-Deep-Learning, commit `e665168b4aefe3256360951504103cf98827ca51`.
- `reviews.txt` dan `labels.txt`: dataset sentimen yang disertakan repositori pendamping.
- `qa1_single-supporting-fact_train.txt`: subset bAbI yang disertakan repositori pendamping.
- `shakespear.txt`: korpus karakter yang disertakan repositori pendamping (nama file mengikuti sumber).
- `spam.txt` dan `ham.txt`: data email yang disertakan repositori pendamping.
- `mnist.npz`: arsip MNIST publik dari mirror dataset Keras; checksum dicatat pada manifest.

Kode notebook menyederhanakan dan memodernisasi contoh agar mandiri di Python 3.12/NumPy. Tidak ada PDF buku dalam paket. LLM digunakan untuk membantu penjelasan teori; mahasiswa wajib meninjau dan memahami hasil sebelum pengumpulan.
